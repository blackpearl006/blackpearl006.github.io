About

I work with the ORIGAMI Lab at the Montreal Neurological Institute (MNI). I work on neuroimaging, medical image analysis and machine learning for brain health. My thesis is on federated learning for Alzheimer's disease progression across imaging sites, where the data stay at each site. I enjoy building open tools that make neuroimaging easier and more fun for everyone.

Projects

I created several open projects, and they are free for everyone to use:

  • NeuroDataHub: a catalogue and downloader for public neuroimaging datasets. 50+ datasets, 50,000+ scans.
  • NeuroLight: a light PyTorch pipeline for deep learning on MR images. Tutorial.
  • NeuroAI Template: a ready-made website for your neuroimaging or brain-AI paper, with interactive 3D brain atlases. Edit Markdown and CSV files, or let an AI agent fill it in from your paper, and publish it free on GitHub Pages. Built with Vite, React, Tailwind, Three.js and NiiVue. Code.
  • BrainAge Fingerprints: an ongoing brain age project on explainable brain-age biomarkers.
  • Recurrence Plots: an interactive site on detecting mild cognitive impairment from fMRI.
  • Getting started with thermal imaging: a site for discovering thermal imaging datasets, with scripts to work with them.

I also contribute to Nipoppy, open and reproducible neuroimaging workflows.
